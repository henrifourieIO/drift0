# Quick Cloudflare Deployment Reference

## First Time Setup
```bash
npx wrangler login
npm run build
npx wrangler pages deploy ./dist --project-name=drift0
```

## Regular Deployment
```bash
npm run cf:build-deploy
```

## Test Locally with Cloudflare Runtime
```bash
npm run build
npm run cf:dev
```

## View Deployments
```bash
npx wrangler pages deployment list --project-name=drift0
```

## Live Logs
```bash
npx wrangler pages deployment tail --project-name=drift0
```

## Configuration Files
- `wrangler.toml` - Main Cloudflare configuration
- `astro.config.mjs` - Uses @astrojs/cloudflare adapter
- `.dev.vars` - Local environment variables (gitignored)

## Dashboard
https://dash.cloudflare.com/ → Workers & Pages → drift0
